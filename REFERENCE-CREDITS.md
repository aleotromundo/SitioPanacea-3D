# Recursos de referencia

Esta versión incorpora una selección ligera de recursos del proyecto **Folio 2025** de Bruno Simon para acercar el lenguaje visual y sonoro del mundo 3D.

- Proyecto original: https://github.com/brunosimon/folio-2025
- Código y modelos: licencia MIT, copyright Bruno Simon 2025.
- Música (`Baguira.mp3`) y efectos: recursos distribuidos en el proyecto original bajo CC0 según la página de referencia.
- Los recursos se mantienen dentro de `client/public/reference-assets/` y se usan como base visual/audio para una experiencia personalizada.

La identidad, textos, composición de la escena y lógica interactiva de Panacea3D son propios de este repositorio.
